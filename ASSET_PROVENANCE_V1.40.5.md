# Card motif asset provenance

Created for this release using the built-in image generation tool. No external stock photos or emoji were substituted. Original generated alpha is preserved; production uses full PNG atlases with CSS cell selection, no destructive raster editing.

Production paths:
- `seasonal-motifs/collection-a.png`: four columns × five rows; New Year, Lantern Festival, International Women’s Day, Hung Kings, Doan Ngo.
- `seasonal-motifs/collection-b.png`: four columns × five rows; Family Day, Vu Lan, National Day, Vietnamese Women’s Day, Culture Day.

Prompt set: realistic photographic miniature decorative cutouts for Vietnamese holidays; exactly four columns and five rows, transparent background, no text/UI/grid lines, generous cell margin, natural light, detailed materials suitable for 64px accents.

A subjects by row: gold watch/ribbon/bow/calendar; red lantern/peach blossom/lotus candle/gold lanterns; tulip bouquet/envelope/single tulip/tulip vase; bronze drum/incense burner/cloud carving/temple ornament; rice dumplings/lychees/bamboo/fermented rice bowl.

B subjects by row: tea set/storybook/jasmine vase/woven basket; lotus/ivory candle/lotus candle/white rose; red Vietnamese flag with one yellow five-pointed star/gold star with red ribbon/red flowers/bronze drum; roses/envelope/conical hat with pink scarf/rose vase; bronze drum/red-gold fan/conical hat with golden silk/cloud ornament.

Existing approved banners and the old ten theme assets are retained unchanged. Animated image fields and cloth are implemented in project-native shaders; this is continuous rendering rather than generated still-frame crossfading.
