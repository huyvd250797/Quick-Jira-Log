# Quick Jira Log Roadmap

- ✅ V0.1.0 – Simple Login & Core Quick Log
  - ID + Password
  - 5 trường KEY / PROJECT / TimeSpent / Date / Description
  - tự xếp giờ trong 08:00–12:00 và 13:30–17:30

- ✅ V0.2.0 – Saved Filter Quick Pick
  - lấy filter `[HuyVo] - No Work Logged`
  - chọn issue ngay trong app
  - tự điền KEY + PROJECT

- ✅ V0.2.1 – Worklog Guard & Summary Autofill
  - không log trùng thời gian
  - chặn ngoài giờ cho phép
  - nhập/chọn KEY tự lấy Summary làm Description

- ✅ V0.3.0 – Quick Input & Templates
  - hiển thị version trong app
  - preset 30m / 1h / 2h / 4h
  - nhớ PROJECT + TimeSpent gần nhất
  - Recent KEY
  - Description Template
  - Quick Repeat

- ⏭️ V0.4.0 – Bulk Logwork
  - chọn nhiều KEY từ filter
  - nhập TimeSpent cho từng issue
  - tự xếp lần lượt vào các khoảng trống trong ngày
  - preview tổng lịch trước khi log

- V0.5.0 – Jira Reliability & Audit
  - retry có kiểm soát
  - log lịch sử thành công/thất bại
  - kiểm tra duplicate request
  - recovery khi Jira timeout

- V1.0.0 – Stable Personal Release
  - PWA/mobile polish
  - hardening security
  - production stability
