# Seasonal card ornament assets — V1.39.9

Ten paired PNG sprites generated using the built-in image generation tool. Transparent RGBA, 1774×887, two square sprite cells. The CSS background size is 200% 100%, left/right cells alternate across cards. Original generated PNGs are retained without cropping or image edits. Asset paths: `/seasonal-ornaments/{tet,vacation,april,children,birthday,moon,school,halloween,teachers,christmas}.png`.

Common final prompt: Production UI decorative sprite asset. A wide horizontal 2:1 transparent canvas with TWO separate small elegant illustration clusters spaced apart, LEFT cluster centered at x=25%, RIGHT cluster at x=75%, each occupying less than 40% canvas width with a generous empty transparent gap. Polished painterly semi-realistic illustration, soft dimensional lighting, detailed crisp shapes, luxurious restrained style for dashboard card corners. No background, no floor, no scene, no text, no frames, no shadows outside the objects, true alpha transparent background. Both clusters fully visible, identical scale and vertically centered, transparent margins all around. Suitable at 90px display size. Make recognizable clear refined objects, few elements.
